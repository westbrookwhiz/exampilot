# ExamPilot

ExamPilot is a guest-friendly educational platform for Zimbabwean O-Level and A-Level candidates, built with React, TypeScript, and Tailwind CSS.

## Features
- Responsive landing pages and navigation
- Subject and revision flows
- Practice questions and mock exams
- Past paper library with sample/demo data notices
- LocalStorage-based guest progress, bookmarks, and study tracking
- Study tools, AI assistant interface, and privacy/disclaimer pages

## Scripts
- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Notes
This initial build uses demo/sample educational content and intentionally avoids login, authentication, and account creation.
